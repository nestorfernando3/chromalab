# ChromaLab Main Room Scene Plan

## Goal
Build the app's main scene as a vivid, theatrical room for teaching color theory.

## Style Direction
Spanish melodrama / domestic-theatre palette: red lacquer, deep cobalt, warm yellow, blush pink, cream plaster, black accents.

## Non-Goals
- No exact imitation of any living filmmaker.
- No generic sci-fi or sterile lab look.

## Room Composition
1. Main Stage — central display area (no head/bust, just the room)
2. Color Salon Wall — swatch display, harmony board, recolorable back wall
3. Living zone — desk, plants, lounge elements
4. Teaching surfaces — swatch shelf, display board, wall dressing

## Asset Strategy
- Kenney Furniture Kit (CC0): walls, desk, plants, ceiling lamp
- Kenney Factory Kit (CC0): pipe accent, screen
- Kenney Prototype Textures (CC0): surface decoration
- Procedural architecture for precise proportions

## Merge Gate
- Feature branch only. No merge to main without review.
- `npm test` and `npm run build` must pass.
- Browser QA pass required.
