# ChromaLab Design Context

## Product
ChromaLab is an interactive 3D color theory learning environment. Students manipulate HSV color, lighting, background, and 3D model variables while following guided lessons. Bilingual (ES/EN).

## Primary Users
- University students learning color theory, visual perception, lighting, design, media, AV production
- Instructors using ChromaLab as in-class demo or guided assignment tool

## Secondary Users
- Self-directed learners exploring color theory
- Designers/media students using the tool as a color-lighting sandbox

## Core User Needs
Students need to:
1. Understand a color theory concept
2. Manipulate color in a 3D environment
3. Observe the perceptual result
4. Explain what changed
5. Save/export evidence of learning

Instructors need to:
1. Present concepts clearly
2. Give students focused tasks
3. Trust that completion means meaningful actions
4. Review evidence when needed

## Brand Personality
- Curious, Precise, Cinematic

## Aesthetic Direction
**Cinematic educational lab**
- Dark, focused environment
- 3D scene as center of gravity
- Warm academic tone (serif typography, intentional microcopy)
- Color used as instructional material, not decoration
- Controls that feel like a creative instrument
- Motion that shows cause and effect

## Product Principle
> The student should never wonder: "What am I supposed to do now?"

## Visual Guidelines
- Dark studio mood
- Source Serif 4 for display, Inter for body UI
- Red (#C41E3A) for brand identity and active states
- Green for completion states
- Educational color palette as learning material
- Neutrals slightly tinted, not pure gray

## Layout Model
Three surfaces:
1. **Lab Surface**: 3D scene, palette strip, scene feedback
2. **Lesson Surface**: mission, active step, observation, completion
3. **Instrument Surface**: controls for palette, light, background, model

## Mental Model
> Mission → action → scene response → reflection → completion

## Accessibility Target
- WCAG 2.2 AA
- Keyboard-only completion
- Touch targets 44px minimum
- Screen reader announcements
- No state communicated by color alone
- Lighthouse a11y score 95+

## Technology
- Three.js for 3D rendering
- Vanilla JS (ES modules)
- CSS custom properties for theming
- Vite for build
- Vitest for tests
- localStorage for persistence
